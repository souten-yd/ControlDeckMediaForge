# MediaForge 0.33.19

単一の参照画像を使う編集が、GPUに空きがあっても通常生成用の小さい枠で失敗する問題を修正。
参照編集の実測枠を別に申告し、PyTorch外の割当も含めたdevice使用量を扱う。
512pxなどの指定寸法に参照画像全体を合わせてから推論し、大きい元画像の寸法で推論しない。
通常の新規画像生成、厳密な部分編集、材質画像編集の既存枠は保持。

DB/public schemaの変更なし。既存画像/3D/Jobs/モデル重みを保持し、モデルの追加取得はない。
0.33.18へサービスを戻せるが、同版では参照編集の小さい枠による失敗が再発しうる。

別方向画像の意味的な正しさや、複数面3D機能の採用を保証するリリースではない。
