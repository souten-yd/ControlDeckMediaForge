# v0.28.68 — Blender修復の登録待ち中の取消・復元

修復の登録処理を待っている間にHost取消や認証喪失が起きた場合、
旧Blenderを破棄する前に取消を再確認し、元の実行環境へ戻します。
停止理由の診断ログも追加しました。限定したエラーコード・状態だけを記録し、
認証トークンや外部エラー本文は出力しません。

公開API・画像/G8・制作物・履歴・版選択の契約は維持します。新しいDB移行はありません。
v0.28.67で追加したHost所有セットアップの旧版rollback制約は引き続き適用されます。
Host所有の未完了操作を残したまま、それを理解しない旧coreへ戻さないでください。

## 検証と残件

PR #463で2件の不具合再現後、関連36テストと全1,604テストが成功しました。
隔離した実Blender 4.5.9で、登録待ち中の取消・認証喪失から旧実行ファイルの
ハッシュ・inode・登録情報が復元されることと、復元後のGLB入出力を確認しました。
Host取消・403応答はこの隔離試験ではfixtureです。

この版の署名公開・導入は準備時点で未実施です。前回の導入版長時間試験で
認証監視が約210秒で途切れた原因は未確定で、本リリースを認証更新の解決とは扱いません。
統合3D Studio・ゲーム制作機能全体と、ゲームエンジン内の受入は未完了です。
