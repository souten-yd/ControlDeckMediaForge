# v0.28.45 — Web Blenderの自動復旧用保存

Web Blenderの隔離された作業ファイルを、2分間隔を目標に自動保存します。
一時ファイルへの書込みが完了してから差し替えるため、保存途中の失敗で
直前の復旧候補を上書きしません。正式な版は従来どおり明示保存で確定します。

自動保存の失敗や結果通知の長時間停止は編集画面へ警告し、次の成功で解除します。
Blenderの操作中などには自動保存が遅れる場合があります。
前回の自動保存より後の編集や、保存中の電源断まで完全に保護する保証ではありません。
利用者の既存Blender・グローバル設定を変更しません。

## 更新・ロールバック

0.28.44からDB/schema/public契約の変更はありません。既存画像機能を保持します。
0.28.44へのrollbackでは定期autosaveとその警告がなくなります。
更新・rollback前には編集中のWeb Blenderを保存して終了してください。
復旧候補は正式版と区別して保持し、利用者の制作データは削除しません。
