# MediaForge 0.33.21

MCPの画像生成・編集スキーマへ、既存のseedと自由形式の追加設定を明示しました。
画像用の設定を先に並べ、3Dの参照画像セットやGLB加工だけで使う項目を
画像要求へ埋めないよう説明を補足しています。

tool名、endpoint、必須項目、参照画像セットの定義、実行処理は維持します。
既存モデルやruntimeの変更、自動ダウンロード、DB移行はありません。
0.33.20へ戻す場合も保存済みの画像・3Dは保持されます。

これは呼出し側へ公開する契約の修正です。1枚から複数方向を作るUIや、
生成された別方向画像の形状一致・自動採用を追加するリリースではありません。
