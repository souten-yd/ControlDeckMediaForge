# v0.28.61 — アニメーションのループ指定案内

OpenCodeへ公開する制作スキーマで、ループするクリップには各々 `loop=true` を
明示する必要があることを説明します。端点の回転が一致するだけではループ検証は
有効になりません。速度の連続性やゲームエンジン側の再生設定は別の確認事項です。

既定false、任意項目、入力制約、worker処理、既存画像・G8・DBは変更しません。
BlenderやHostの更新、モデルの追加取得は不要です。

## 検証と残件

PR #433では全1509テスト、viewer build、実source HTTPでの3スキーマ配信を確認しました。
説明以外の契約は旧版と同一です。

旧0.28.60の実OpenCode試験は自動ウェイト・2クリップ・GLB配置まで完走し、
再読込で変形も確認しましたが、両クリップのloop指定省略により依頼全体は不合格でした。
今回の説明が指定漏れを防ぐ効果は、署名版導入後の実OpenCodeで再検証します。
複雑なキャラクター品質、歩行・IK、ゲームエンジン導入、全3D Studio受入は未完了です。
