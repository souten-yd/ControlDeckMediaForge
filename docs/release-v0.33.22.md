# MediaForge 0.33.22

「作る → 3D」で正面画像を選び、「別方向の候補を作る（実験的）」から
右側面・背面・左側面の候補を作れるようにしました。既存の参照画像編集を使い、
元画像と並べて向き・形・持ち物を確認した候補だけを、追加方向へ選べます。
簡易モードの「状況」からも比較画面へ戻れます。PC・320pxの操作に対応します。

候補は通常の画像としてライブラリへ保存し、元画像と方向を来歴へ残します。
履歴を消しても元画像別の候補を再表示できます。複製画像、別の元画像からの候補、
削除済み画像は採用時に拒否します。生成完了だけで3Dを自動開始しません。
従来の1枚生成と、自分で2〜4面を用意する操作も使えます。

生成画像の方向や形状の一致は保証されません。特に人物の持ち物や左右が変わる
ことがあるため比較が必要です。実モデルの候補品質は実行ごとに確認してください。

新しいモデル・runtime・重み取得・DB移行はありません。既存tool/APIの必須項目は
維持し、来歴用の任意contextを追加します。0.33.21へ戻しても画像・3D・Jobは保持
されますが、新しい比較UIは使えず、1件だけの候補batchは旧版で表示できません。
