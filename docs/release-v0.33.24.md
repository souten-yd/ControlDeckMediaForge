# MediaForge 0.33.24

画像から3Dを作る際、正面に追加する方向を右側面・背面・左側面から選べます。
正面＋左側面、正面＋背面など、必要な画像だけで2〜4面を組み合わせられます。
選んだ方向のカメラ角度を保持し、追加順によって向きが変わることはありません。

別方向のAI候補を採用した際も、その方向だけを追加します。
先行する方向の空欄を埋める必要はありません。簡易・詳細・モバイルで操作でき、
既存の1枚生成、重複画像の拒否、画像の来歴、実行中の削除保護を維持します。

モデル・runtime・DBの変更やモデルの追加ダウンロードはありません。
0.33.23へ戻しても生成済み素材は保持されますが、新たに可能になった方向の組合せの
依頼・再試行には0.33.24以降が必要です。斜め方向や画像ごとの任意角度指定は含みません。
