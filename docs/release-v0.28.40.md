# v0.28.40 — まとめて頼んだときの進捗報告

0.28.39 の `media.generate.batch` が、実機の本番経路で 2 件目以降を落としていました。
N 件を 1 つの Host Job にぶら下げますが、Host の進捗制限（0.5 秒間隔・単調増加）は
Host Job に対して掛かります。件ごとに新しい門を作っていたため、前の件の最後の報告と
次の件の最初の報告が同じ 0.5 秒に入り、429 で弾かれていました。門を batch で 1 つに
します。

あわせて、進捗の報告が拒まれても生成を殺さないようにしました。終端の通知は以前から
失敗しても job の結末を残す作りでしたが、途中の報告は例外がそのまま上がっていました。
進捗の報告は job の結末ではありません。

## 検証

導入済み Host・実 GPU で、OpenCode の MCP 経路から 3 件バッチを実行して確認しました。
単体テストは 1169 件が成功しています。

## 更新・ロールバック

0.28.39 からデータ変換はありません。0.28.39 への rollback は保存形式互換ですが、
まとめて頼んだときの 2 件目以降が再び失敗します。公開契約は変更していません。
