# v0.28.67 — BlenderセットアップのHost認証・取消連携

設定から開始するBlender/Web環境の導入・更新・修復・切替・正確な版の導入・削除を、
所有者付きのHost Jobへ接続します。実行待ちから認証を更新し、接続切断後も処理を追跡します。
Host取消や認証喪失では、開始済みのファイル処理を回収してから終端を記録します。
Hostの終端通知が届かなかった場合は、再認証済み所有者の設定状態照会で照合します。
Host自身の取消理由は上書きせず、通知内容の不一致も記録に残します。

公開API・画像/G8・制作ファイル・履歴・Blenderの版選択と参照保護は維持します。
ローカル操作に不要なHost Jobを追加しません。認証トークンはDBやグローバル設定へ保存しません。

## DB移行とrollback

既存セットアップ記録へ非公開の所有者・Host Job・終端照合項目を追加します。
更新前のDB/Blender登録snapshotを保持してください。旧記録はローカル操作として維持します。
新core再起動時に認証を失ったHost所有操作は停止し、元のruntime・partial・制作物を保持します。
旧coreはこの所有権を理解しないため、Host所有の未完了操作を残したままdowngradeしないでください。
新coreで停止・照合してから戻すか、書込み停止下で更新前DB snapshotを復元してください。
