# v0.28.49 — 3D制作の失敗箇所を特定

型付きBlender制作が途中で失敗したとき、操作番号・種類・対象のstable IDと
限定した理由をJobのエラーへ返します。たとえば存在しない対象への変形を、
単なる「出力ファイルがない」ではなく、何番目のどの対象で失敗したかとして確認できます。
生のBlender例外・内部パスは公開しません。不正な診断は一般エラーへ戻します。
失敗した途中状態を採用せず、元の制作版を保持します。

## 検証と配布状態

PR #373で実装。実Blender4.5.9/4.5.13の隔離source環境で、
ボーン・クリップ追加・クリップ置換後に不正操作を実行し、失敗箇所と旧版保持を確認。
不正JSON・版/index不一致・サイズ上限・symlink・FIFO・directoryとfd保持を検査しています。
この文書作成時点では配布準備中です。署名公開・導入環境のMCP受入は未実施です。
最新の実測と配布状態は[実装状況](implementation-status.md)へ記録します。

LLMによる自動修正、歩行・滑らかなウェイト・IK/FK・ゲームエンジン再生、
3D Studio全体の完成を宣言する版ではありません。

## 互換性

DB migration、公開schema/tool名、capabilityの追加はありません。
既存のscene_recipe_failedとerror.messageを使います。
診断の得られるエラーではmessageが具体化されるため、完全一致の文言に依存しないでください。
修正入力は新しいedit試行として送ります。同入力のretryとは区別します。
Blender runtimeのpin、制作物・旧revision、利用者のグローバル設定は変更しません。
更新/rollback前にGUIを保存・終了し、稼働Jobがないことを確認してください。
