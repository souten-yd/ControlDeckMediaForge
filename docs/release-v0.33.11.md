# MediaForge 0.33.11

直立人物の自動ボーン配置と歩行を修正します。

- 胴と左右の腕を複数の断面で検出し、頭・上腕・前腕・手の骨を配置。
- 手を脚の測定に混ぜず、膝を胴体の高さへ誤配置する問題を修正。
- 人物の脚は前後へ振り、放射状多脚用の横振りによる脚の交差を防止。
- 軽量化後の断面欠落と幅広の靴に対応。4本脚・6本脚の既存歩行は維持。

対象は正立・左右X軸の人物で、腕と胴の隙間がある形状です。任意の姿勢の人物を
保証しません。既存の保存版は変更せず、同じ元モデルへの新しいボーン設定で反映します。
生成テクスチャの色ずれは別の課題です。DB/API契約とHostコードの変更はありません。
