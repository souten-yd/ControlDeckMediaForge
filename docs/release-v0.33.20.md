# MediaForge 0.33.20

画像から3Dを作る画面に、右側面・背面・左側面の画像追加を実装。
独立した複数面runtimeを実測・採用した環境では、正面と右側面の2枚、
背面を加えた3枚、全4枚からPixal3D/Vulkanで生成できる。
各方向のプレビュー、端末からの追加、差し替え、削除に対応し、
追加を外すと従来の1枚生成へ戻る。簡易モードでは推奨設定を使い、
詳細モードから共通カメラの画角・距離・仰角・倍率を変更できる。

全画像は背景透過のPNG/WebP、同じ正方形サイズ（64〜2048px）と撮影条件が必要。
別名でも同一の実画素は拒否し、全画像の来歴と生成中の削除保護を保持する。
複数面は実験的で、任意の写真の校正や自動的な別方向画像の生成は含まない。
既存の「同じ画像からtrellis.cpp版とPixal3D版を作る」操作の文言も実態に合わせた。

APIは`additional_views`と`view_camera`の追加のみ。DB移行はない。
既存の単視点runtime・モデル・Assetを保持し、更新に伴うモデルの自動取得はない。
複数面runtime未採用時は追加機能を利用可能と表示しない。
0.33.19へ戻す場合は複数面Jobを終端にしてから戻す。生成済みの画像・3Dは残るが、
旧版では複数面要求の再試行を利用できない。
