# v0.28.63 — モバイルでのWeb Blender操作

狭い画面でBlenderを開く・復旧する操作の幅制限を除き、全画面レイアウトと
Esc/Tab/Enter/矢印の入力補助を追加します。細かな編集にはPC・キーボード・マウスを推奨します。
runtime未導入・編集中の競合・認証などの保護は変わりません。

補助キーは最後に選択したBlender画面内の位置へポインターを戻してから送信し、
別の編集領域へEnterが届く問題を修正します。切断後に遅れてキーを送信しません。
opaque iframeでタップ後のクリック先がずれる問題には、Blender操作ボタンに限定した
タップ処理を追加しました。ドラッグ・複数指・無効ボタン・canvas操作は対象外です。

画像・G8・公開API・制作版の契約は変更しません。DB移行、HostやBlenderの更新、
モデルの追加取得は不要です。

## 検証と残件

PR #441で実Chromeの日英6画面条件、opaque iframeのタップ、入力抑止を確認しました。
source UIを使った320pxの実Blender接続では、タップで開く・補助Enter・保存を実行し、
24→30fpsへの変更と旧5版の保持を確認しています。文字入力とcanvas focusはキーボード・マウスです。
保存ファイルの独立Blender読込、全1537テスト、viewer build、Nodeテストも通過しています。

このリリースの署名公開・導入されたUIの初期化と同操作は準備時点で未検証です。
物理モバイル端末・IME・ゲームエンジンへの導入・全3D Studio受入の完了を意味しません。
