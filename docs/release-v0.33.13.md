# MediaForge 0.33.13

MCPの画像→3D→ボーン→書き出しで、失敗した工程だけを再試行できます。
成功済みの画像や3Dを作り直さず、元の設定を引き継ぎます。

状態取得で確認した失敗Jobを指定して明示的に再試行します。同じ要求の二重送信、
別ユーザーの操作、実行結果が不明な工程の再実行を防ぎ、失敗履歴を保持します。
次の工程の確認待ちは維持します。新しい引数は追加のみで、既存操作は変わりません。

0.33.11の人物歩行と0.33.12の微小な重み欠損の修正を含みます。
DB migration/Hostコード/生成モデルの変更はありません。
保存するpipeline JSONには失敗履歴が加わります。旧版はこのfieldを読めないため、
downgrade時は更新前のdata snapshotとの整合を確認する必要があります。
