# v0.28.80 — Web Blenderの編集入口を表示

Web Blender画面の先頭に「Blenderで編集」と設定への入口を表示します。
シーンを選ぶ前は編集を無効にし、対象の選択、.blendの取り込み、OpenCodeで制作した後の
一覧更新を案内します。選択した対象名を表示し、選択を解除すると編集も無効に戻ります。
既存の復旧・保存・再接続・単一編集セッションと環境不足時の制約は維持します。

v0.28.79の画像生成・量子化・lease持ち回りの変更を保持します。
DB migration、公開API、Blenderの登録、既存制作物への変更はありません。
旧版へのサービスrollbackには今回追加のDB復元は不要ですが、編集入口は旧表示に戻ります。

ソースUIでは実Chromeの日英・320px/1280pxで入口表示、設定への移動と戻る、横overflowなしを確認しました。
これは稼働.79の読み取り応答に候補UIを重ねた検証です。実GUI編集やHost iframe受入とは区別します。
選択解除とscene名のliteral表示はブラウザ内fixtureで確認し、制作物・Job・backupを作成していません。

**OSの隔離設定をコード入力なしで導入する機能は、まだ提供していません。**
今回の設定ボタンは既存のBlender環境設定へ移動するものです。
診断用AppArmor profileの成功を本番GUIの完全隔離や永続設定の完成とは扱いません。
画面からの直接新規シーン作成、物理モバイル操作、統合3D Studio全体とゲーム制作の全受入も未完了です。

署名配布・導入版の結果は `docs/implementation-status.md` へ実測後に記録します。
版数更新後の全テストは1850件成功、3件スキップ（206.71秒）。Node9件とviewer buildも成功しています。
