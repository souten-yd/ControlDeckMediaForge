# v0.28.58 — 3Dの固定個数配列

型付き制作操作に`modifier.array`を追加します。階段・柵・モジュール部品などを、
元形状を含む2〜64個の非破壊配列として制作できます。
`local_offset`はローカル座標での間隔です。objectの拡大率・回転が実際の間隔と方向に影響します。

## 安全性と互換性

一つのobjectにつき配列は一つ。ゼロ間隔、不正な個数、親・制約・アニメーション・
shape key付きmeshは拒否します。配列と後続の複製・ミラー・ベベルによる形状増幅は
生成前に予算を検査します。任意Pythonや外部参照は公開しません。
既存の画像・G8・scene recipe操作、データベース構造、制作済みの版は変更しません。
新操作はcapabilitiesと公開schemaに存在するときだけ使用してください。
旧版では新操作を実行できませんが、既存操作の意味は維持します。

## 検証と残件

PR #421のsource実機受入でBlender4.5.13と4.5.9を使用。
6段・72三角形の実評価48座標とGLB再読み込み結果が一致し、別版での2m移動後も
旧blend/GLBのハッシュを保持しました。二重配列と過大なベベルは版を確定せず拒否しました。

署名公開・導入済みMCP/OpenCodeの受入は準備時点では未実施です。
配列は形状の一体化ではなく、Boolean接合・ボーン変形・歩行・エンジン取り込みや
ゲーム制作品質の完成を意味しません。詳細は[実装状況](implementation-status.md)。
Hostの予約受付修正（ControlDeck PR #311）は別の更新であり、このbundleでは配布しません。
