# v0.28.60 — 自動ボーンウェイト割当て

3D制作の型付き操作に`skin.bind_auto`を追加します。既存の剛体割当て`skin.bind`は
変更せず、複数のボーンの影響を受けるメッシュを制作できるようにします。
待機・曲げなどのクリップは既存の`animation.clip`で追加できます。

## 入力と安全性

- `object_id`: 静止・標準変換のMediaForge製骨格。
- `mesh_object_ids`: 未割当ての独立したメッシュ1〜16個。
- 親・ウェイト・制約・アニメーション・shape key・modifierがあるメッシュは拒否します。
- 頂点・面・ボーンとの組合せに上限を設け、縮退面や不正な変換を処理前に拒否します。
- Bone heatの結果を検査し、最大4ボーンの影響へ正規化します。未割当てや不正値は失敗とし、
  別の割当て方式へ自動変更しません。失敗した制作工程は旧版を上書きしません。

既存画像・G8・公開済み操作の契約、DB、runtime登録は変更しません。
旧MediaForgeは新しい操作を受理できないため、利用可能な操作一覧と配信スキーマを確認してください。
既存Blender環境の再導入、Hostの変更、モデルの追加取得は不要です。

GLB再読込後の5時刻の変形、再割当て拒否、後続工程失敗時の旧版保持を実機確認しました。
ソース版の全1,487テスト、フロントエンドビルド、既存剛体ボーンの実機回帰が成功しています。

DB全テーブルとBlender登録を保持し、稼働exeと配信スキーマが監査済み配布物に一致しました。
実Host MCPで自動割当てと2クリップを制作し、GLB配置・再読込・同時刻変形を2.112秒で確認しました。
