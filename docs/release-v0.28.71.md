# v0.28.71 — Web Blenderのファイル読み取り制限

配布準備中。まだ署名公開・導入確認はしていません。

Web Blenderの専用プロセスで、許可した制作領域と必要な実行環境以外の
ファイル読み取り・一覧表示・実行を拒否します。従来の書き込み制限だけでは、
許可外ファイルを読み取れることを無害な検証ファイルで確認したための修正です。
必要なBlender資源・OSライブラリ・フォント等だけを明示的に許可し、
Hostのデータ全体や利用者のホーム全体を許可しません。

ソース版の実Blender4.5.13で許可外の検証ファイルの読み取り拒否を確認しました。
4.5.9と4.5.13の両方で、通常bootstrapによる起動、RFB画面データ受信、
切断後の再接続、保存、終了を確認し、元アセットは保持されています。
通信層での再接続であり、ブラウザ操作全体の受入とは区別します。
続く独立ソース環境では実Chrome/noVNCで編集・切断・再接続を確認し、
既定の自動保存後に検証専用Blenderを異常終了させ、編集した2メッシュを別シーンへ復旧できました。
127.064秒で成功し、元の正式版を保持しています。Host内の導入版受入は別途必要です。
版数更新後の全1,793テストが204.70秒で通過し、viewer build差分0、Node5テストも成功しました。
先行試験の初期設定タイムアウト1件は原因未確定として記録を保持しています。

DB・公開契約・Blender登録・元の制作物・利用者のグローバル設定は変更しません。
旧版へ戻すと読み取り制限も旧状態に戻るため、Web Blenderの利用再開には注意が必要です。
Unixソケット・継承ファイル記述子・プロセス情報の隔離は別の検証対象です。
本修正をもって統合3D Studio全体、Expert実行、ゲーム用アセット制作の完成とはしません。
