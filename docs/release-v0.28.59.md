# v0.28.59 — アセット配置の引数案内

OpenCodeなどのエージェントが`media.pack`を呼び出す際に、単一配置と一括配置を
混ぜないよう、公開ツールスキーマの全体・各引数の説明を明確にします。
1ファイルでは単一形式を推奨します。入力の型、必須項目、上限、排他条件は変更しません。

## 互換性

- 単一形式: `output_grant_id`、`asset_id`、必要なら`filename`。`items`は省略。
- 一括形式: `output_grant_id`と`items`。最上位の`asset_id`と`filename`は省略。
- 混在入力は書込前に拒否します。nullや重複した値を付けて代用しないでください。
- 一括配置はファイル単位の確定です。全件をまとめて原子的に確定するものではありません。

画像・G8・Blender制作操作、既存の配置形式・受領書、DB・制作ファイル・runtime登録は
変更しません。Hostの変更やBlenderの再導入は不要です。
