# v0.28.57 — 資源予約失敗時のHost Job状態を同期

画像・材質生成の資源予約が失敗したとき、MediaForge側だけが失敗となり、
所有するControlDeck Jobが「実行中」に残る通知漏れを修正します。
Hostへ終端を通知できない場合でも、MediaForgeには元の失敗理由を残します。
呼出し元が所有する親Jobを、MediaForgeが勝手に終了させることはありません。

## 検証と配布状態

PR #416で修正前の3ケースを再現し、対象5ケースの回帰を確認しました。
sourceから実HostへHTTP通知し、専用Jobの両側がfailedとなることも確認済みです。
この検証は資源予約失敗だけを注入しており、画像生成成功の証拠ではありません。
署名公開・導入済み環境の修正受入は、リリース準備時点では未実施です。
最新の実測は[実装状況](implementation-status.md)に記録します。

## 互換性と残件

公開API・schema・tool・DB形式・Blender runtimeは変更しません。
既存画像・G8・制作物・履歴を保持し、実行中JobとGUIがない時に更新してください。
資源予約の応答自体を受け取れず、予約IDが不明になった場合の自動回収は別の残件です。
終端通知の再不通に対する永続的な再送を追加した変更ではありません。
統合3D Studio全体、ゲーム内受入、有機変形・IK・歩行は引き続き開発中です。
