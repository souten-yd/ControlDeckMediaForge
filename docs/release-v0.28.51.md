# v0.28.51 — Web Blender再接続時の誤終了を修正

Blenderの稼働確認を待つ間に画面接続が切れると、古い時刻で切断猶予を判定して
セッションを誤終了する競合を修正します。非同期の確認後に最新状態を読み直します。
0.28.50の入力だけを数える無操作判定は維持し、無操作30分・切断猶予5分を延長しません。

## 検証と配布状態

PR #381で修正。0.28.50の実機30分診断は約15分で切断猶予切れとなり失敗しました。
失敗を再現するテストは修正前に失敗、修正後に成功しています。
修正後の実source Blender4.5.9では入力時刻・再接続・既定自動保存を確認し、
所有Blender子のcrash後に同hashの2 meshesを回収しました（138.523秒）。
実装時の全テストは1345 passed（既知warning2）。
この文書の準備時点で本修正の署名公開・導入と既定30分完走は未検証です。
最新の状態は[実装状況](implementation-status.md)に記録します。
