# v0.28.54 — 制作Jobの重複取消時の参照回収

Blender制作Jobの受付中に取消が重なると、不要な「使用中」参照が残り、
環境の削除を拒否し続ける問題を修正します。
開始済みの参照取得・解放を最後まで追跡してから取消を返します。
Host受付失敗時と制作終了時の解放も同じ保護を適用します。

## 検証と配布状態

PR #397で実装。取消2回・3回で参照が残る問題をテストで再現して修正しました。
全1,361テスト、ビューワービルド、アニメーション表示5テストが成功しています。
隔離した実Blender4.5.9でも、重複取消後に参照が0件へ戻り、続く通常制作と
GLB検証が成功することを確認しました。Host応答・取得遅延は明示的な試験用fixtureです。
署名公開・公開4ファイルの再取得照合・実Hostの署名検証を確認しました。
標準更新10.052秒でhealthyとなり、DB全テーブルとBlender登録を保持しています。
導入後の実ブラウザでも、削除確認後にGUIが始まる場合の削除拒否、
Blender画面表示、旧シーン保持と試験用セッションの終了を確認しました。
導入済みHostでの重複取消そのものの受入は未実施です。
最新の実測は[実装状況](implementation-status.md)に記録します。

## 互換性と残る範囲

公開API/schema/tool名、DB、Blender版・archive identityの変更はありません。
既存画像・G8加工・ビューワーを維持します。稼働JobとGUIがない時に更新してください。
実行中のBlenderを強制終了する変更ではなく、開始済み資源回収の追跡を補強する修正です。
統合3D Studio全体と、ゲーム制作向けの有機変形・IK・歩行等は引き続き開発中です。
