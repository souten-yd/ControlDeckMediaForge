# v0.28.48 — 作成済みアニメーションクリップの修正

`animation.clip`に任意の`replace: true`を追加します。
同じ骨格の既存クリップを、新しい制作版の中で修正できます。
回転キー・長さ・表示名・ループ検証指定を置換し、他のクリップと旧制作版は保持します。
省略時は従来どおり追加専用です。存在しないIDへの置換、共有action、FPS変更は拒否します。
同じ32クリップ・キー数・サンプル数の上限を維持します。

## 検証と配布状態

PR #370で実装。実Blender4.5.9/4.5.13の隔離source環境で、
腕振りを1秒/60度から2秒/30度へ修正し、旧版・待機クリップの保持とGLB再importを確認。
不正入力5種類、32クリップでの反復置換、失敗recipeによる新revision非採用を検査しました。
署名公開・導入環境の受入は別途[実装状況](implementation-status.md)へ記録します。

前回の自然言語制作で検出したロボットの隙間や指定漏れを、自動で修正済みとする版ではありません。
歩行、滑らかなウェイト、IK/FK、ゲームエンジン再生の完成も宣言しません。

## 互換性

DB migrationはありません。recipe@1の追加fieldだけで、旧operationの意味は維持します。
旧bundleはreplace付きrecipeを受理できません。使用前に現在のMCP schemaを確認してください。
Blender runtimeのpinや利用者のグローバル設定は変更しません。
更新/rollback前にGUIを保存・終了し、稼働Jobがないことを確認してください。
制作物・旧revisionは保持します。
