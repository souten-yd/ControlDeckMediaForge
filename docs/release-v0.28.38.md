# v0.28.38 — 素材割り当て失敗後の比較表示

画像素材の割り当てに失敗したとき、比較画面が「読み込み中」のまま残る問題を修正します。
元の版が変更されていないことと割り当て失敗を日英で表示し、採用操作は無効のままにします。
画面を閉じて同じ画像・対象で再試行し、成功した候補を比較してから採用できます。

source standaloneの実HTTP/WebSocket・Blender・Chromeで、日本語320pxと英語1280pxの
失敗→再試行→比較→採用を確認しました。初回worker対象だけを故障注入し、元画像・元版の
不変と選択保持を検査しています。画像は既存の実生成PNGを取り込んだもので、新規生成は
行っていません。この証拠を導入済みHostの受入やAgent retry_job_idの検査へ読み替えません。

公開契約・保存形式・runtime registry・依存は変更しません。Blender本体やモデル重み、
利用者のグローバル設定も変更しません。統合3D Studio全体の必須受入はPARTIALです。
本版は署名公開物の再取得・Host信頼鍵での検証を終え、標準更新14.189秒で
0.28.38/healthyを確認しました。更新前後8テーブル全行とBlender管理情報は不変です。
新バンドルの日英320px Library回帰と、導入済み320/1280pxの実関連素材63件の
ページ送り・日英切替・選択保持も成功しています。素材失敗・再試行の
導入済みHostでの受入は未実施であり、source試験と区別します。
