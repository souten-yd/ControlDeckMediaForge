# M4 — bounded UV and CPU normal/AO bake

Source slice on `ux1/3d-surface-bake`, parent PR542/c208c67. Existing scene
Jobs/Asset/immutable revision storage, no Host/model/runtime installation changes.

Four additive recipe operations provide hash-pinned seam marking, unwrap, pack
and static scale application. `media.scene.bake` pins owner-scoped low/high
revisions and runs a fixed CPU worker. Normal requires high geometry; AO is
isolated target AO. UV facts are carried through material-only revisions.
Existing normal material binding consumes the generated Asset.
