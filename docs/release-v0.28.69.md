# v0.28.69 — Blender環境の反映・中断回復と結果表示

Blenderの導入・更新・修復で、反映開始と終了結果を永続記録します。
反映開始前の取消は以前の状態を保ち、開始後に届いた取消・認証喪失は別の補足として記録します。
中断後は実体・登録・世代・ハッシュを照合し、確認できた完了を回収するか、未反映の候補を戻します。
確認できない実体は削除せず保護します。起動時の照合はバックグラウンドで行います。

設定画面では処理ごとに、回復結果、遅延した取消、Host側との終了記録の不一致を日英で説明します。
Hostが取消済みなら成功へ上書きしません。再認証後の照合でも同じ規則を守ります。
有効な認証でのHost制御GETが特定の読み取りエラーになった場合だけ、1回再照会します。
Job作成・通知などの書き込みを自動再送する変更ではありません。

## 更新と旧版への復帰

既存 `blender_runtime_operations` にprivateなnullable `publication_json` 列を追加します。
既存操作の列はNULLのまま移行し、画像・G8・制作物・履歴・公開APIの契約を維持します。
利用者のグローバル設定や外部Blenderへは書き込みません。

旧coreは新しい公開journalを解釈しません。未確定の公開を残したまま実行ファイルだけ旧版へ
戻さないでください。新coreで照合・回収を済ませるか、書き込みを止めて更新前の整合した
DB・runtime登録情報と対応する実体のバックアップから復旧してください。
バックアップへ戻すと更新後の記録も巻き戻るため、更新後の制作物と記録は先に退避してください。
v0.28.67以降のHost所有セットアップに関する旧版復帰の制約も引き続き適用されます。
